# Proposed changes

Changes proposed in Holland's "Fixing Silksong's ... Crest" series
([playlist](https://www.youtube.com/playlist?list=PLOkGZTjTZ_Mlh9yaNjvVGT2tbgU-b32Kc)).
How the game currently behaves is documented in [the knowledge base](knowledge-base/README.md).

Status: done, planned (tuning of existing mechanics), deferred (new feature, done separately).

## Series-wide

| Proposal | Status |
|---|---|
| Every crest except Vesticrest has at least one yellow and one blue tool slot | waiting for the Beast/Witch videos |
| Movement actions (dash, cloak, double jump) are not blocked right after attacking; attack, Clawline, silk skills and bind may stay blocked | done, per crest |

## Hunter ([video](https://www.youtube.com/watch?v=0CXRQrCVhxk))

| Proposal | Status |
|---|---|
| Down attack (pogo) without windup | done |
| Sprint slash without startup delay | done |
| Needle strike second slash does not push Hornet back | done |
| Taking damage removes 6 focus instead of all | done |
| Tool slots unchanged | – |

## Reaper ([video](https://www.youtube.com/watch?v=85iHI9G8mDM))

| Proposal | Status |
|---|---|
| Up slash hitbox in front of Hornet instead of behind | done |
| Sprint slash without startup delay | done |
| Needle strike with a bigger hitbox (no value given; default 1.25x) | done |
| Down slash keeps its slow attack speed but loses the windup, the input-eating frames and the forced diagonal movement | done |
| Silk Steal (bind effect): fixed Silk fragment count per hit instead of random 1-3 | done |
| Bind: needle strike drops significantly more fragments | done |
| Bind: taking damage does not end Silk Steal; each successful attack reduces the remaining duration by 1 s instead | done |
| Harvest Bind: Up + Bind for 4 silk grants Silk Steal without healing | done |
| Tool slots unchanged | – |

## Wanderer ([video](https://www.youtube.com/watch?v=yMxEuaWvhGQ))

| Proposal | Status |
|---|---|
| Sprint slash without startup delay | done |
| Replace the 2% critical hit passive with Critical Strike: needle hits fill a harp, a full harp makes the next needle strike a guaranteed 3x critical hit | deferred |
| New needle strike: a single powerful swipe (alternative: every strike of the current one gives silk) | deferred |
| Tool slots unchanged | – |
